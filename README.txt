Hidden Submarine — 雙視角 UI

執行方式：用 Safari、Chrome 或其他現代瀏覽器開啟 index.html。

玩家視角：不顯示未擊沉船隻。點擊格子攻擊；只在右側回報 Hit/Miss/Sunk，格子保持海水。擊沉後船完整顯示。
後台視角：顯示所有船目前位置、方向、受損部位、移動紀錄。切換視角不會重置遊戲。

規則：8x8，船長 4、4、3、3、2、2；不可與其他船重疊或八方向相鄰；只有當次命中尚未受損部位且未擊沉的船有 50% 機率合法平移一格；重複命中已受損部位不增加傷害，也不移動；損傷隨船移動；所有部位受損才擊沉。

新遊戲：重新隨機排船。
重新開始同一盤：回復初始船位與傷害。

本版本僅含手動遊戲及除錯視角，未加入 BFS/DFS 自動求解。
